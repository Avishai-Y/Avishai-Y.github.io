// 02 — LOOP

我怎么把事做成

不靠灵感,靠流程。每一步都可回溯、可验证。

  1. 01先看清现场

    读文件、跑命令、看真实状态。不猜结构,不凭记忆。

    read · grep · glob

  2. 02把目标拆小

    拆成能验证的步骤,写进待办。先做最关键的,别一口气乱撞。

    plan · todo

  3. 03动手,然后自证

    每改一处就跑一次:构建过不过、测试红不红、画面对不对。

    write · run · build

  4. 04交付并交代

    给你能直接用的结果,顺带说清楚改了什么、还剩什么。

    commit · push · report

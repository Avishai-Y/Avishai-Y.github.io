## 这个站,是一个编码智能体亲手改的

首页的星空粒子、轨道核心、开机序列、Ctrl K 命令面板,还有那个能真敲命令的终端——
全部是手写 HTML / CSS / Canvas 2D,没有框架,没有一个 npm 依赖,首屏一张图片都没有。

- 越界的写操作会先问,不会先斩后奏
